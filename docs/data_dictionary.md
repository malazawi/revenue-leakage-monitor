# Data Dictionary

Brightwater Advisory Partners is a fictional consulting firm. All data in this repository is synthetic: it was generated by [`scripts/generate_data.py`](../scripts/generate_data.py) with a fixed random seed, so running the script reproduces every file exactly.

Data runs from **Jan 1, 2024 to Oct 16, 2026** (the snapshot date).

| File | Rows | Grain |
|---|---|---|
| `staff.csv` | 150 | One row per professional |
| `clients.csv` | 450 | One row per client |
| `engagements.csv` | 1,800 | One row per engagement (project) |
| `time_entries.csv` | ~189K | One row per time entry |
| `invoices.csv` | ~16K | One row per invoice |
| `payments.csv` | ~16K | One row per payment received |
| `collections_log.csv` | ~8K | One row per collections contact |
| `ar_exceptions.csv` | ~60 | Invoices flagged Disputed or Payment plan |
| `ar_aging_for_agent.csv` | ~1.2K | Open-invoice snapshot the Collections Agent reads |

## staff
| Column | Description |
|---|---|
| staff_id | Key (ST001…) |
| staff_name, email | Randomly generated name and firm email |
| title | Partner, Director, Senior Manager, Manager, Senior Consultant, Consultant |
| office | Minneapolis, Charlotte, Phoenix, Columbus, Salt Lake City |
| practice | Practice group |
| standard_rate | Hourly standard rate (USD) |
| monthly_target_hours | Billable hours target per month |

## clients
| Column | Description |
|---|---|
| client_id | Key (C0001…) |
| client_name, industry, region | Invented client name and attributes |
| payment_terms_days | 30 (most) or 45 (Healthcare, Public Sector) |
| ap_contact_name, ap_contact_email | Accounts payable contact (`@example.com`) |

## engagements
| Column | Description |
|---|---|
| engagement_id | Key (E00001…) |
| client_id | → clients |
| engagement_name, practice | Description |
| billing_partner_id | → staff (the partner responsible for billing) |
| fee_type | Hourly, Fixed Fee, Capped |
| agreed_discount_pct | Negotiated discount off standard rates |
| start_date, end_date | Engagement dates |

## time_entries
| Column | Description |
|---|---|
| entry_id | Key |
| engagement_id, staff_id | → engagements, staff |
| work_date | Date the work was performed |
| entry_date | Date the time was entered in the system |
| entry_lag_days | entry_date − work_date |
| hours, standard_rate, standard_value | Hours × rate = standard value |
| invoice_id | → invoices (blank = still unbilled WIP) |
| billed_value | Amount actually billed for this entry (after discounts and write-downs) |

## invoices
| Column | Description |
|---|---|
| invoice_id | Key |
| engagement_id, client_id | → engagements, clients |
| invoice_date, due_date | Due date = invoice date + payment terms |
| standard_value | Standard value of the time billed |
| invoice_amount | Amount billed |
| write_off_amount, write_off_date | Bad-debt write-off, if any |

## payments
| Column | Description |
|---|---|
| payment_id | Key |
| client_id | → clients |
| received_date, amount, method | Cash received (ACH, Wire, Check) |
| remittance_invoice_id | Invoice the payment was intended for |
| applied_invoice_id, applied_date | Invoice it was applied to, and when (blank = **unapplied cash**) |

## collections_log
| Column | Description |
|---|---|
| contact_id | Key |
| invoice_id | → invoices |
| contact_date, method | Email, Phone, Partner call |
| outcome | No response, Promise to pay, Acknowledged, Dispute |
| promised_date | Date the client promised to pay (if any) |

## ar_exceptions
| Column | Description |
|---|---|
| invoice_id | → invoices |
| exception_type | Disputed or Payment plan (excluded from outreach) |
| flag_date | When it was flagged |

## ar_aging_for_agent
Open invoices as of the snapshot date, with everything the Collections Agent needs: client and partner contacts, balance, days past due, aging bucket, last contact, broken promises, exception flag, plus a precomputed `eligible_for_outreach`, `priority_score` and `recommended_action` used to check the agent's output against a known answer.
